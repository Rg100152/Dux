# ⚡ Dux

A lightweight, high-performance, and modular web architecture boilerplate integrating **HTML5**, **CSS3**, **JavaScript**, **TypeScript**, and **Tailwind CSS**.

Designed with strict separation of concerns, dark-mode aesthetics, and production-grade developer tooling out of the box.

---

## 📁 Repository Structure

```text
Dux/
├── index.html           # Main semantic markup and layout
├── style.css            # Base styles, custom scrollbar & animations
├── app.js               # Client-side DOM manipulation & event handlers
├── main.ts              # Strongly typed logic, state management & interfaces
├── tailwind.config.js   # Tailwind theme extensions & dark mode config
├── tsconfig.json        # TypeScript compiler configurations
├── package.json         # Project metadata, scripts, and dependencies
└── README.md            # Project documentation & setup guide
